# Sơ đồ Thiết kế Hệ thống CANi (System Diagrams)

Thư mục tổng hợp các sơ đồ kỹ thuật của dự án CANi:
- **Use Case Diagrams:** Mô hình tương tác giữa 4 vai trò chính (Admin, Customer Care, Event Organizer, Worker).
- **Sequence Diagrams:** Luồng đăng ký/đăng nhập, Matching đề xuất ca, điểm danh QR hai chiều, khai báo thù lao trực tiếp & đối soát.
- **Entity-Relationship Diagram (ERD):** Cấu trúc thực thể quan hệ cơ sở dữ liệu.
